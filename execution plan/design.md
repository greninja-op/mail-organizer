# Mail Organizer — Visual & UX Contract

Mail Organizer is a personal information organization/action system, not a Gmail clone.

## Values
Clarity, trust, privacy, intelligence, control, speed and calmness.

## Visual language
Clean modern productivity UI; subtle depth; soft surfaces; restrained elevation; rounded components; strong typography; subtle dividers; contextual status colors. Avoid excessive gradients, glassmorphism, neon and skeuomorphism.

## Typography and spacing
Inter preferred/system fallback. Display 32–36px; large title 28; title 22; section 18; body 16; secondary 13–14; caption 12. Use a 4dp grid: 4/8/12/16/20/24/32/40/48/64. Radii 8/12/16/20/pill.

## Information architecture
Primary navigation: Home, Mail, Categories, Companies, Actions. Secondary: Search, Integrations, Settings, Privacy, Accounts. Home is attention-first: account context → Action Required → High Priority → Recent Mail → category overview → company context.

## UX rules
Organization over chronology. Progressive disclosure. Real data only; no fake production counts/messages/companies/action items. Provide loading, empty, error and offline states. Dark mode is first-class. Accessibility and responsive layouts are mandatory. Motion: 100–150ms micro, 200–300ms standard, 300–400ms complex.

## Product principle
Email → Understand → Organize → Prioritize → Act.
